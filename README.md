# PSOSENSE (Discontinued Project)

## 📌 About
**PSOSENSE** was a project started in **2023** and maintained until **August 25, 2025**.  
It was originally developed as an experimental toolset for *Pro Soccer Online*, focusing on technical exploration such as DLL injection, loaders, memory manipulation, and modular C++ design.

The project is now permanently discontinued.

---

## 📂 Repository Contents
This repository contains the **legacy source code** and related materials of PSOSENSE, including:

- **`autogk_dll/`** → experimental automation module  
- **`new_loader/`** → updated loader implementation  
- **`psosense/`** → main core of the project  

---

## ⚠️ Important Notice
- This project is **discontinued** and **no longer works** with *Pro Soccer Online*.  
- The repository is kept **for educational and research purposes only**.  
- There is **no support, maintenance, or updates**.  
- The code should **not be used** in any active or online games.
